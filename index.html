GPU Acceleration in Optimization and Optimal Control

Pre-congress workshop WS-12 at the 23rd IFAC World Congress — BEXCO Room 103, Busan, Sunday 23 August 2026, 08:30–12:00 KST.
Organizer: Sungho Shin, Massachusetts Institute of Technology.

  • Lecture slides (PDF)
  • Hands-on notebooks
    • GPU computing in the Julia language
    • Optimal control and parameter estimation on GPUs
    • Worked solutions to the exercises: minimum-time swing-up · particle steering
    • The notebook server link for the live session is provided during the workshop.
    • To run them locally on an NVIDIA GPU: notebooks and Julia environment

The lecture covers nonlinear optimization, optimal control as a structured nonlinear program, and GPU acceleration; the hands-on session works through the two notebooks above, using ExaModels.jl and MadNLP.jl on a hosted GPU environment. No GPU programming experience is required; bring a laptop with a web browser.
